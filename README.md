# sit-lab-report

一个 [DeepSeek Harness](https://github.com/deepseek-ai) 技能：**把纸质大学物理实验报告录进学校的报告系统**。

不是替你写报告的作弊工具 —— 它解决的是「纸质报告已经写好了，还要在七栏富文本里再录一遍、每栏还得贴照片」这件纯体力活。

> 面向上海应用技术大学的物理实验中心系统（`210.35.98.35` + EasyConnect 内网 VPN）。别的学校流程不同，只能当参考。

## 它做什么

1. 开 EasyConnect 内网 VPN
2. 登录基础信息平台 → 从侧边栏带会话进报告系统
3. 打开待填报告，七栏逐个填：
   - **纸上有的**：手机照片裁成三块（目的 / 仪器 / 原理）+ 数据页整页，直接贴原图
   - **纸上没有的**：简述实验步骤、数据处理、结果分析与讨论 → 由模型按原理和数据补写
4. 点「临时提交」，**不点「正式提交」**

## 依赖

- [DeepSeek Harness](https://github.com/deepseek-ai)（DSH）
- `computer_*` 工具族 —— 来自 DSH 电脑操作插件（截图 / 点击 / 键盘 / 窗口 / UI Automation）
- 目标机器：Windows（EasyConnect 客户端 + Edge）

## 安装

```powershell
# 用户级技能目录
git clone <this-repo> "$env:USERPROFILE\.dsh\skills\sit-lab-report"
```

或者直接把 `SKILL.md` 丢进 `~/.dsh/skills/sit-lab-report/SKILL.md`。

DSH 会在下次加载技能目录时识别（通常不用重启）。

## 用之前必须改的地方

SKILL.md 里的**屏幕坐标是某一台机器、某一个窗口尺寸下的实测值**，换机器必然对不上。

先看这句约定：

```
所有屏幕坐标基于 Edge 窗口 2259x1374、原点 (254,122)、截图 scale 0.55
屏幕坐标 = 窗口原点 + 图内坐标 / scale
```

第一次用的时候：

1. `computer_screenshot` 截一张 Edge 全窗，看返回里的 `at (x,y)` 和图像尺寸
2. 按上式把文档里的坐标全部换算成你自己的
3. 截图里量准「用户名框 / 密码框 / 登录按钮 / 左侧四个图标 / 相机 / 点击上传 / 临时提交」的位置

坐标错一位，点击就落到别人身上 —— 这是这个技能最容易翻车的地方。

## 核心策略：只贴图，不重打

纸质报告上已经有的内容（目的、仪器、原理图、数据表），**拍照裁图直接贴**，比 OCR 再重排快得多也准得多。只有纸上是空白的栏（步骤、数据处理、分析讨论）才让模型写。

这也是为什么技能里有一大段讲裁剪和上传 —— 这块是最耗时的。

## 已知坑（都写进 SKILL.md 第 9 节了）

- 点击被别的窗口抢前台 → 每个 batch 里先 `focus`
- 中文路径在文件对话框里被截断 → 用纯 ASCII 路径 + 只输文件名
- 直接访问报告系统子域名会掉会话 → 必须从侧边栏点进去
- 模态框的 ✕ 点不掉 → `F5` 刷新
- 贴完一张图页面高度变化 → 下一栏坐标全部重算

## 边界

- 不编造实验数据：缺条件（如入射光功率、波长）只给公式，不填数字
- 数据有异常会主动指出来，不硬圆
- 默认只点「临时提交」，正式提交留给人确认
